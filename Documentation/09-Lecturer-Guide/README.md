## Role Overview

As a Lecturer, you are responsible for teaching units, managing course materials, grading assessments, tracking attendance, and monitoring student progress. The Lecturer Portal provides tools to manage all teaching-related activities.

---

## Getting Started

### Logging In
1. Navigate to the system login page
2. Enter your username and password
3. Click **Login**

### First-Time Login
1. If you receive a temporary password, you will be prompted to change it
2. Create a new password (must meet complexity requirements)
3. Update your profile information if needed

### Navigating the Lecturer Portal
The sidebar provides access to:
- **Dashboard**: Overview of your teaching units and activities
- **My Units**: Units you are assigned to teach
- **Students**: Students enrolled in your units
- **Assignments**: Create and manage assignments
- **Grades**: Enter and manage student grades
- **Attendance**: Record and manage attendance
- **Reports**: Generate unit reports

## Teaching Units

### Viewing Your Assigned Units
1. Navigate to **My Units**
2. View all units assigned to you for the current academic period
3. Each unit shows:
   - Unit name and code
   - Credit hours
   - Number of enrolled students
   - Class schedule

### Unit Details
Click on a unit to view:
- Unit description
- Learning outcomes
- Enrolled students list
- Assessment structure
- Uploaded materials
- Assignment schedule

### Confirming Teaching Assignments
If you have been assigned to a new unit:
1. Navigate to **Assignments** > **Pending Confirmations**
2. Review the unit assignment details
3. Click **Accept** to confirm the teaching assignment
4. Click **Decline** with a reason if you cannot teach the unit

## Uploading Notes

### Uploading Course Materials
1. Navigate to **My Units** > **Select Unit**
2. Click **Upload Material**
3. Select the file category:
   - Lecture Notes
   - Slides
   - Reading Materials
   - Past Papers
   - Other Resources
4. Choose the file to upload
5. Add a description (optional)
6. Click **Upload**

### Supported File Types
- PDF (.pdf)
- Word Documents (.doc, .docx)
- PowerPoint (.ppt, .pptx)
- Excel (.xls, .xlsx)
- Images (.jpg, .jpeg, .png)
- ZIP Archives (.zip)

### File Size Limits
- Maximum file size: 10 MB (configurable by administrator)
- Files larger than the limit will be rejected

### Managing Uploaded Files
1. Navigate to **My Units** > **Select Unit** > **Materials**
2. View all uploaded materials
3. Download, replace, or delete files as needed

## Assignments

### Creating an Assignment
1. Navigate to **My Units** > **Select Unit**
2. Click **Assignments** > **Create Assignment**
3. Enter:
   - Title
   - Description/instructions
   - Due date and time
   - Maximum score
   - Weight (percentage of final grade)
4. Attach any supporting files
5. Click **Save**

### Managing Assignments
1. Navigate to **Assignments**
2. View all assignments for your units
3. Options:
   - **Edit**: Modify assignment details
   - **Delete**: Remove the assignment
   - **Extend Due Date**: Postpone the deadline
   - **View Submissions**: Review student submissions

### Viewing Submissions
1. Navigate to **Assignments** > **Select Assignment**
2. Click **View Submissions**
3. See all student submissions:
   - Student name
   - Submission date/time
   - Status (Submitted, Late, Missing)
   - File attachments

## Grading

### Grade Entry Process
1. Navigate to **My Units** > **Select Unit**
2. Click **Grades**
3. View the grade entry grid showing:
   - Student names
   - Assessment types (CAT, Exam, Practical, etc.)
   - Current marks
   - Weighted scores
4. Enter or update marks for each student
5. Click **Save** to commit changes

### Grade Types
The system supports multiple assessment types:
- **Continuous Assessment Test (CAT)**
- **Examination**
- **Practical/Project**
- **Assignment**
- **Presentation**
- **Other** (configurable)

### Automatic Grade Calculation
The system automatically:
1. Multiplies each assessment score by its weight
2. Sums the weighted scores
3. Calculates the final grade
4. Maps the total to a grade band (A, B, C, etc.)

### Grade Change History
All grade changes are tracked:
- Who made the change
- When the change was made
- Previous value
- New value

## Weight Configuration

### Understanding Weights
Weights determine the contribution of each assessment to the final grade.

Example:
| Assessment | Weight | Max Score |
|------------|--------|-----------|
| CAT 1 | 10% | 30 |
| CAT 2 | 15% | 30 |
| Assignment | 15% | 20 |
| Exam | 60% | 100 |
| **Total** | **100%** | - |

### Configuring Weights
1. Navigate to **My Units** > **Select Unit**
2. Click **Assessment Structure**
3. For each assessment type, set:
   - Weight percentage
   - Maximum score
   - Number of assessments
4. Click **Save**

> **⚠️ WARNING**: Total weights should equal 100%. The system will warn if they do not.

## Manual Mark Entry

### Entering Marks Manually
1. Navigate to **My Units** > **Select Unit**
2. Click **Grades** > **Manual Entry**
3. Select the assessment
4. Enter marks for each student directly
5. Use bulk entry options to paste marks from Excel
6. Click **Save**

### Bulk Mark Entry
1. Export the mark entry template (Excel)
2. Fill in student marks in Excel
3. Import the completed file back
4. Review and confirm the imported marks

## Attendance

### Recording Attendance
1. Navigate to **My Units** > **Select Unit**
2. Click **Attendance** > **Record**
3. Select the class date
4. Mark each student as:
   - Present
   - Absent
   - Late
   - Excused
5. Click **Save**

### Viewing Attendance Records
1. Navigate to **Attendance** > **History**
2. View attendance records by date and unit
3. See summary statistics:
   - Attendance rate per student
   - Class attendance average
   - Absentee patterns

### Exporting Attendance
1. Navigate to **Attendance**
2. Configure the date range
3. Click **Export**
4. Download as PDF or Excel

## Student Progress

### Viewing Student Progress

## Frequently Asked Questions

**Q: How do I add a new assessment type?**
A: Navigate to the unit's Assessment Structure and add a new assessment type with its weight.

**Q: Can I edit grades after saving?**
A: Yes, navigate to Grades, make changes, and save. All changes are tracked in the grade change history.

**Q: How do I handle late submissions?**
A: Late submissions are automatically marked as "Late" based on the due date. You can still grade them.

**Q: What if I need to remove an uploaded file?**
A: Navigate to Materials, find the file, and click Delete. The file will be removed from student access.

**Q: How do I know if I've been assigned a new unit?**
A: You will receive a notification. Navigate to My Units to view all assignments.
