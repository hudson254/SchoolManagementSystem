## Role Overview

Coordinators (also referred to as Moderators) are responsible for academic coordination and oversight. They bridge the gap between administrators, lecturers, and students, handling approvals, course assignments, and academic management.

### Coordinator Capabilities
- Approve/reject student registrations
- Approve/reject lecturer registrations
- Assign courses to academic periods
- Assign units to courses
- Manage timetables
- View student and lecturer records
- Generate academic reports
- Manage notifications
- Perform password resets for users

## Student Approval

### Viewing Pending Student Registrations
1. Navigate to **Approvals** > **Pending Registrations**
2. The list shows all students who have registered but not yet been approved
3. Each entry shows:
   - Student name
   - Email
   - Course selected
   - Registration date
   - Status (Pending)

### Approving a Student
1. Navigate to **Approvals** > **Pending Registrations**
2. Find the student to approve
3. Review their details to ensure they are legitimate
4. Click **Approve**
5. The student will receive a notification that their account is active

### Bulk Approving Students
1. Navigate to **Approvals** > **Pending Registrations**
2. Select multiple students using checkboxes
3. Click **Bulk Approve**
4. Confirm the approval
5. All selected students will be approved simultaneously

### Rejecting a Student Registration
1. Navigate to **Approvals** > **Pending Registrations**
2. Find the student and click **Reject**
3. Enter a reason for rejection (required)
4. Click **Confirm Reject**
5. The student will be notified of the rejection with the reason

## Lecturer Approval

### Viewing Pending Lecturer Registrations
1. Navigate to **Approvals** > **Pending Lecturer Registrations**
2. The list shows lecturers pending approval
3. Each entry shows:
   - Lecturer name
   - Email
   - Title (Dr., Prof., etc.)
   - Department
   - Registration date

### Approving a Lecturer
1. Navigate to **Approvals** > **Pending Lecturer Registrations**
2. Find the lecturer to approve
3. Review their qualifications and details
4. Click **Approve**
5. The lecturer will receive a notification

### Rejecting a Lecturer Registration
1. Navigate to **Approvals** > **Pending Lecturer Registrations**
2. Find the lecturer and click **Reject**
3. Enter a reason for rejection
4. Click **Confirm**

## Course Assignment

### Creating Course Offerings
1. Navigate to **Course Offerings** > **Create New**
2. Select:
   - Course
   - Academic year
   - Semester
   - Mode of study (Full-time, Part-time)
3. Set enrollment start and end dates
4. Click **Save**

### Assigning Units to Course Offerings
1. Navigate to **Course Offerings** > **Select Offering**
2. Click **Add Units**
3. Search and select the units to include
4. Configure unit delivery details
5. Click **Save**

---

## Unit Assignment

### Assigning Lecturers to Units
1. Navigate to **Course Offerings** > **Select Offering**
2. Find the unit to assign
3. Click **Assign Lecturer**
4. Search for the lecturer
5. Select the lecturer and click **Assign**
6. The lecturer will receive a notification about the assignment

### Managing Unit Allocations
1. Navigate to **Units** > **Unit Allocations**
2. View which lecturers are assigned to which units
3. Reassign or remove lecturers as needed

---

## Timetable Management

### Creating a Timetable Entry
1. Navigate to **Timetable** > **Create Entry**
2. Select:
   - Unit
   - Lecturer
   - Day of week
   - Start time
   - End time
   - Room/location
3. Click **Save**

### Viewing Timetables
1. Navigate to **Timetable** > **View**
2. Filter by:
   - Lecturer
   - Unit
   - Day
   - Course offering

### Editing Timetable Entries
1. Navigate to **Timetable** > **View**
2. Find the entry and click **Edit**
3. Modify the required fields
4. Click **Save**

## Student Management

### Viewing Student List
1. Navigate to **Students** > **Student List**
2. Search and filter students by:
   - Name
   - ID number
   - Course
   - Status

### Viewing Student Details
1. Navigate to **Students** > **Student List**
2. Click on a student name
3. View:
   - Personal details
   - Enrollment history
   - Grades
   - Attendance records
   - Accommodation status

### Managing Student Enrollments
1. Navigate to **Students** > **Enrollments**
2. View current and past enrollments
3. Add or drop enrollments as needed

## Academic Records

### Viewing Academic Records
1. Navigate to **Academic Records**

   - Grades achieved

## Reports

### Available Reports
| Report Type | Description |
|-------------|-------------|
| Enrollment Report | Students enrolled per course/offering |
| Grade Report | Grades by unit, student, or course |
| Attendance Report | Student attendance summaries |
| Lecturer Load Report | Units assigned per lecturer |
| Timetable Report | Schedule overview |

### Generating Reports
1. Navigate to **Reports**
2. Select the report type
3. Configure filters (date range, course, unit, etc.)
4. Click **Generate**
5. Download as PDF or Excel

## Approvals

### Pending Approvals Dashboard
The approvals dashboard shows:
- Pending student registrations
- Pending lecturer registrations
- Pending enrollment confirmations
- Pending teaching assignment confirmations

### Managing Approvals
1. Navigate to **Approvals** > **Dashboard**
2. Review each pending item
3. Approve, reject, or defer as appropriate

## Notifications

### Sending Notifications
1. Navigate to **Notifications** > **Create**
2. Select recipients (by role, course, or individual)
3. Enter title and message
4. Set priority
5. Click **Send**

### Viewing Sent Notifications
1. Navigate to **Notifications** > **History**
2. Filter by date and recipient

## Account Management

### Creating User Accounts
Coordinators can create accounts for:
- Students (with Student role)
- Lecturers (with Lecturer role)

### Editing User Profiles
1. Navigate to **Users** > **User List**
2. Find the user and click **Edit**
3. Modify profile information
4. Click **Save**

---

## Password Resets

### Resetting a User Password
1. Navigate to **Users** > **User List**
2. Find the user and click **Reset Password**
3. A temporary password will be generated
4. Provide the temporary password to the user securely

> **⚠️ WARNING**: Only reset passwords for verified users. Always verify the user's identity before providing a new password.

---

## Role Limitations

Coordinators **cannot**:
- Create or delete Administrator accounts
- Modify system-level configuration
- Access system audit logs (except for educational scope)
- Delete courses or units
- Modify system security settings
- Access other tenant's data
- Perform database maintenance operations

Coordinators **can**:
- Manage users within their scope (students, lecturers)
- Create and manage course offerings
- Assign units and lecturers
- Approve/ reject registrations
- Generate academic reports
- Manage timetables
