## 4. Multi-Tenancy

### 4.1 Tenant Isolation

Every table contains a `TenantId` column to ensure data isolation between tenants.

```sql
-- Example: Tenant isolation query filter
SELECT * FROM Students WHERE TenantId = @CurrentTenantId;

-- Row Level Security (RLS)
CREATE POLICY tenant_isolation ON Students
    USING (TenantId = current_setting('app.current_tenant_id')::UUID);
