## 1. Introduction

Welcome to the School Management System. This guide is designed for lecturers and covers all features available to teaching staff.

### 1.1 Purpose

The School Management System enables lecturers to:
- Manage teaching units
- Upload lecture notes
- Create and grade assignments
- View student enrollment
- Track student progress

### 1.2 System Requirements

- Modern web browser (Chrome, Firefox, Edge, Safari)
- Internet connection (or LAN access)
- PDF creation software for lecture notes
- File management for assignment materials

---

## 2. Getting Started

### 2.1 Registration

**Step 1:** Navigate to the School Management System login page.  
**Step 2:** Click **"Create Account"**.  
**Step 3:** Select **"Lecturer"** as your role.  
**Step 4:** Fill in the registration form:

| Field | Description | Required |
|-------|-------------|----------|
| First Name | Your first name | Yes |
| Last Name | Your last name | Yes |
| Email | Your institutional email | Yes |
| Password | Minimum 8 characters with complexity | Yes |
| Confirm Password | Re-enter your password | Yes |
| Phone Number | Your contact number | Yes |
| Organization | Your institution | No |
| Specialization | Your area of expertise | No |

**Step 5:** Click **"Register"**.  
**Step 6:** Wait for moderator verification (see Section 2.2).

### 2.2 Account Verification

**Step 1:** After registration, your account will be pending verification.  
**Step 2:** You will receive an email when your account is verified.  
**Step 3:** If not verified within 48 hours, contact the moderator.

> **Note:** Only verified lecturers can access teaching features.

### 2.3 Logging In

**Step 1:** Navigate to the login page.  
**Step 2:** Enter your email and password.  
**Step 3:** Click **"Sign In"**.

## 5. Lecture Notes

### 5.1 Uploading Notes

**Step 1:** Navigate to the unit.  
**Step 2:** Click **"Lecture Notes"**.  
**Step 3:** Click **"Upload Notes"**.  
**Step 4:** Enter details:

| Field | Description | Required |
|-------|-------------|----------|
| Title | Title of the lecture notes | Yes |
| Description | Brief description | No |
| File | The lecture notes file | Yes |

**Step 5:** Select the file (PDF, Word, PowerPoint, etc.).  
**Step 6:** Click **"Upload"**.

> **Best Practice:** Use PDF format for lecture notes to ensure compatibility.

### 5.2 Managing Notes

**Step 1:** View your uploaded notes.  
**Step 2:** Edit notes:

- Update title
- Update description
- Replace file

**Step 3:** Delete outdated notes.

### 5.3 Version Control

**Step 1:** When updating a note, a new version is created.  
**Step 2:** Students can view the latest version.  
**Step 3:** Previous versions are archived.

## 6. Assignments

### 6.1 Creating Assignments

**Step 1:** Navigate to the unit.  
**Step 2:** Click **"Assignments"**.  
**Step 3:** Click **"Create Assignment"**.  
**Step 4:** Fill in the details:

| Field | Description | Required |
|-------|-------------|----------|
| Title | Assignment title | Yes |
| Description | Detailed description | Yes |
| Max Score | Maximum points possible | Yes |
| Weight | Percentage of final grade | Yes |
| Due Date | Submission deadline | Yes |
| Closing Date | Late submission cut-off | No |
| Instructions | Detailed instructions | No |
| Attachments | Additional files | No |
| Late Submission | Allow late submissions | No |
| Late Penalty | Penalty percentage per day | No |

**Step 5:** Click **"Create"**.

### 6.2 Managing Assignments

**Step 1:** View all assignments for the unit.  
**Step 2:** Edit assignments:

- Update due date
- Modify instructions
- Change marks
- Delete assignment

**Step 3:** Publish or unpublish assignments.

### 6.3 Viewing Submissions

**Step 1:** Click on an assignment.  
**Step 2:** Click **"View Submissions"**.  
**Step 3:** View submission list:

| Column | Description |
|--------|-------------|
| Student | Student name and number |
| Submission Date | Date submitted |
| Status | Submitted/Late |
| File | Download link |
| Actions | Grade/Feedback |

### 6.4 Grading Submissions

**Step 1:** Click **"Grade"** on a submission.  
**Step 2:** Enter the score:

- Max score: [value]
- Student score: [enter]

**Step 3:** Add feedback (optional).  
**Step 4:** Click **"Submit Grade"**.

### 6.5 Providing Feedback

**Step 1:** In the grading interface, enter feedback in the comments section.  
**Step 2:** Provide constructive comments:

- Strengths
- Areas for improvement
- Suggestions

**Step 3:** Submit the feedback.

## 12. Frequently Asked Questions

### 12.1 Verification

**Q:** How long does verification take?  
**A:** Verification typically takes 24-48 hours. Contact the moderator if delayed.

### 12.2 Assignments

**Q:** Can I edit an assignment after publishing?  
**A:** Yes, but avoid changing due dates after publication without notifying students.

### 12.3 Grading

**Q:** Can I regrade a submission?  
**A:** Yes, updates will be reflected immediately.
